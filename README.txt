# 🚀 SAATHI

---

## 🏗️ Architecture Overview

SAATHI is built on a modern, decoupled architecture designed for scalability and performance:

* **Frontend:** [Next.js](https://nextjs.org/) + [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
* **Backend:** Next.js API Routes (Serverless)
* **Database & Auth:** [Supabase](https://supabase.com/)
* **Artificial Intelligence:** [Google Gemini API](https://ai.google.dev/)
* **Deployment:** [Vercel](https://vercel.com/)

---

| **Authentication** | [Supabase Auth](https://supabase.com/auth) |

* **AI Model Provider:** [Google Gemini API](https://ai.google.dev/)
